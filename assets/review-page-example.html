停止触发不是新稳态

判据是电流过零、之后不再承受正向电压——不是电压过零。

一页速记

  1. 关断的判据是电流降到维持电流以下，且之后不再承受正向电压；电压过零只是让电流有机会下降。
  2. 阻感负载电流连续时，正在导通的那对管子没有「下一对」来接电流，电感把电流按原方向顶住，管子继续导通。
  3. 停止触发后，ud 变负，电感储能经导通管与负载放完，电流单调衰减到零——这是一次暂态，不是新的周期稳态。
  4. 电阻负载 id 与 ud 同形，电压过零电流同步到零，不需要换流通路，自然关断。
  5. 半波整流本身仍要每周期触发一次，这恰好反证「停止触发还能周期性工作」不成立。

1阻感负载单相桥式全控整流电路，停止给下一对晶闸管发脉冲后，正在导通的那对管子为什么关不断？

对。关断靠电流：电流降到维持电流以下、且之后不再承受正向电压。这里卡在「电流降不下来」——没有下一对管子接电流，电感把电流按原方向顶住。

看电流，不看电压。停止触发只是不再换流；没有另一对管子接过电流，电感维持的电流没有去处，管子只能继续导通。

为什么

晶闸管是半控器件：门极只能开通，关断靠电流。停止触发取消的是「下一对管子的开通时刻」，正在导通这对管子的正向电压和电流都还在，所以它维持导通。

2阻感负载全控桥停止触发后，电路进入什么状态？

对。ud 在这段时间变负，把电感能量送回电源侧；电流单调衰减到零，之后所有管子关断。它不会自己变成另一种周期性工作方式。

半波整流本身仍要每周期触发一次，所以「停止触发 → 还能周期性工作」是自相矛盾的。这里发生的是一次暂态，不是新稳态。

为什么

电感储能只能经导通管与负载泄放，ud = −u2 的区间就是它在把能量送回电源。电流到零后，管子因电流不足以维持而关断，之后 ud 由负载决定，不再有周期波形。

3同样的停止触发，电阻负载为什么能自然关断？

对。电阻负载 id 与 ud 同形，电压过零电流也过零，电流自然降到维持电流以下。阻感负载缺的正是这一步。

晶闸管没有「自动关断信号」，也不靠过热。区别只在电流能否过零：电阻负载能，阻感负载不能。

为什么

电阻负载 id = ud / R，电压过零时电流同时到零；没有 L 的储能，也就没有「必须找到换流通路」这个问题。

4判断晶闸管能否关断，正确的判据是？

对。这是唯一能在波形上检验的判据：先看电流能不能降下来，再看关断后有没有正向电压把它重新开通。

电压过零只是让电流有机会下降，不是判据本身；触发脉冲和触发角都不决定关断。

为什么

两个条件都要满足：电流过零回答「能不能关」，之后的正向电压回答「会不会又被开通」。缺一个就会得出错误结论。
